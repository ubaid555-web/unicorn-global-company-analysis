# Unicorn Global Company Analysis
An end-to-end data analytics project on global unicorn companies, using Python, SQL, Excel, and Power BI to turn a raw dataset into actionable insights.

## Project Overview
This project covers the complete analytics lifecycle on a raw Kaggle dataset: data cleaning and preprocessing, exploratory data analysis (EDA), SQL-based KPI analysis, Excel pivot tables and charts, and interactive Power BI dashboards.

## Dataset
Source: [Kaggle – Unicorn Companies Dataset](https://www.kaggle.com/datasets/adilshamim8/startup-growth-and-investment-data))

## Tools & Technologies
- **Python:** Pandas, NumPy, Matplotlib
- **SQL:** MySQL (subqueries, window functions, analytical functions)
- **Excel:** Pivot Tables, Pivot Charts
- **Power BI:** Interactive dashboards

## Project Workflow
1. **Data Cleaning & Preprocessing:** resolved null and unknown values using Pandas and NumPy to improve data quality.
2. **Exploratory Data Analysis:** examined distributions, relationships, patterns, and trends with Matplotlib visualizations.
3. **SQL Analysis:** wrote queries on the cleaned dataset to extract insights and calculate KPIs.
4. **Excel Analysis:** built Pivot Tables and Pivot Charts for a clearer view of the results.
5. **Power BI Dashboards:** designed interactive dashboards to communicate insights and support data-driven decisions.

## Key Insights
- United States has the most companies and invested most fundings
- Fintech industries dominates other industries
- Bytedance has the most valuations

## Repository Structure
- `notebook.ipynb`: Python cleaning and EDA
- `queries.sql`: SQL queries
- `data/`: dataset files
- `images/`: dashboard screenshots
- `dashboard.pbix`: Power BI file
